# Fast Development

Build useful, maintainable software quickly with a simple design suited to
the current task.

Prioritize fast delivery of complete, readable, maintainable functionality.

- Prefer readable, modular implementations that fit existing responsibilities
  and conventions.
- Verify important behavior and common edge cases with focused checks.
- Use focused automated tests for important behavior and common edge cases.
  Add integration checks when component tests cannot establish a required
  interaction.
- Avoid unnecessary concurrency, abstractions, infrastructure, and premature
  optimization.
- Keep planning and documentation proportionate to actual dependencies,
  contracts, and risks.
