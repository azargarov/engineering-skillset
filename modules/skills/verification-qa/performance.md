## Performance verification

1. Measure the representative workload against the stated performance
   requirement. Use benchmarks and profiling to explain observed changes.
2. Check memory and other resource use when they are part of the requirement
   or a plausible regression risk.
3. Verify relevant concurrency, race, resource-limit, and regression behavior
   when the implementation uses those mechanisms or requirements depend on
   them.
4. Recheck functional correctness while optimizing, and report measurement
   conditions and unverified claims.
